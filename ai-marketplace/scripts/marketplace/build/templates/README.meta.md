# README.meta.md

Specification for the [distribution README template](README.md).

## README.md goals and principles

- Gives visitors to generated repositories the installation instructions for their host and a route to the source marketplace's usage documentation.
- Keeps plugin descriptions and examples in the main repository rather than duplicating them across distributions.
- Remains reusable across marketplaces; instance identity and installation text come from source configuration, not this template.
