# ZDreamer2 plugins marketplace

This repository owns the `ai-doc` and `ai-marketplace` source plugins, including
the marketplace builder and reusable marketplace codebase guidance. GitLab is
the source of truth; the public source mirror is `github.com/ZDreamer2/ai-plugins`.
The BiCo marketplace and its PHP build integration are separate codebases.

[Maintaining AI Plugins](../../../docs/Maintaining.md) owns local build/test
commands and publication boundaries. Generated host distributions are separate
repositories, not source-editing targets. Marketplace-wide concrete guidance
lives here; reusable marketplace conventions belong to `ai-marketplace/codebase/`.
