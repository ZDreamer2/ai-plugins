# Read ai-doc by short name

Run `python3 ./Tools/print-ai-doc-by-ref.py` with the caller’s reference name as one argument, or no argument when no name is supplied.

Read the printed document and use it for the caller’s request. An empty or unknown name prints the available-reference registry instead.
