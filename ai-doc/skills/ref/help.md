# ai-doc:ref

Prints ai-doc plugin documents by short name.

## Usage

`${AGENT_SKILL(ai-doc:ref)} <name>`

## Available references

- stress-test - Shared editorial criteria for critically assessing AiDoc changes
- StartSimple - Iterative documentation approach, start minimal and expand from evidence
- HumanDoc - Format specification for human-facing documentation
- AiDocBaseFormat - Foundation format for AI-optimized documentation
