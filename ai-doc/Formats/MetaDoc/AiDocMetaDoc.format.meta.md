# AiDocMetaDoc.format.meta.md

Specification for creating and editing [AiDocMetaDoc format](AiDocMetaDoc.format.md). Defines purpose, usage patterns, and constraints.

## AiDocMetaDoc.format.md goals and principles

- Defines the shared standard for metas as explanations of a target's purpose, use and important boundaries for future editors.
- Makes that standard usable during both creation and review. A structurally valid meta can still add little editing context; the format explains the contribution that matters.
- Distinguishes enduring intent and rationale from the target's current contents. Metas can precede their targets without becoming advance procedures or freezing document-level choices.
- Uses descriptive goals and examples to establish the target as the subject. In the motivating session, imperative goals survived review because the guidance and its own metas did not consistently express that distinction.

## AiDocMetaDoc.format.md typical use context

### 💡 Distinct usage patterns for AiDocMetaDoc.format.md

#### Loaded by the meta creation workflow

The ai-doc skill dispatches a meta request to the creation workflow, which loads this specification to create or improve an AiDocMetaDoc.

- Primary format specification defining what AiDocMetaDocs are and how to write them
- Establishes structure and standards for all AiDocMetaDoc creation
