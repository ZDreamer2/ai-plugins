# Creating a New BaseDoc From Scratch

## BaseDocs have no fixed structure

BaseDoc format defines no required sections or template. Each document organizes content based on its specific purpose. This freedom makes the blank-page start harder — there is no template to fill in.

## Start with the header outline

The first good step is to draft the header structure — section names and their ordering — WITHOUT writing actual content. This forces decisions about scope and organization before getting pulled into prose.

While drafting that outline, think about:

- What the document needs to accomplish — what decisions or actions it supports
- What content belongs here vs in neighboring docs that already exist
- [AiDoc writing principles](../../Theory/AiDocBaseFormat.md) - how to structure content for AI processing

Confirm the outline with the user then continue as you see fit
