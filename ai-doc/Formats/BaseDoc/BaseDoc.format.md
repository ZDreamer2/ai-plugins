# BaseDoc Format Specification

## What is document in BaseDoc format

A document in BaseDoc format is an AiDoc that guides AI during practical tasks without requiring specialized structure. These documents organize content naturally based on their specific purpose while adhering to AiDocBaseFormat principles.

## MUST read before planning BaseDoc document

- [AiDoc writing principles](../../Theory/AiDocBaseFormat.md) - MUST comply with all its principles

## SHOULD read for additional context before planning BaseDoc document

- [Creating a new BaseDoc](OnNewBaseDoc.md) - Read when creating a new BaseDoc from scratch

## BaseDoc template

BaseDoc has no required structure. Organize content to best serve the document's purpose while following [AiDoc writing principles](../../Theory/AiDocBaseFormat.md).

## BaseDoc example

BaseDoc has no fixed structure, so no single example represents all valid organizations. Refer to [AiDoc writing principles](../../Theory/AiDocBaseFormat.md) for principles that ALL BaseDoc documents share.

## Validation Rules

- MUST follow all principles from [AiDoc writing principles](../../Theory/AiDocBaseFormat.md)
- MUST NOT use bold formatting anywhere in the document
- MUST use RFC 2119 directive terms correctly (MUST/SHOULD/MAY)
- MUST use ASCII text for emphasis instead of Unicode symbols
